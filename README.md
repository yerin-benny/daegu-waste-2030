# 덜 버리는데, 가장 많이 묻는 도시 — 대구 생활폐기물 데이터 진단과 2030 시뮬레이터

2026 대구광역시 기후·환경·탄소중립 공공데이터 AI 활용대회 [부문2] 공공데이터 분석·시각화 출품작입니다.

대구는 1인당 쓰레기 발생량이 전국 평균보다 적지만 매립률은 17개 시도 중 가장 높습니다. 2024년 생활폐기물 공공데이터를 시도·구·군·성분 단위로 분석해 원인을 찾고, 2030년 생활폐기물 직매립 금지와 탄소중립 목표에 맞춰 무엇을 얼마나 줄여야 하는지 계산했습니다.

- 대시보드: `index.html` (게시 주소에서 바로 열립니다)
- 인쇄본: `dashboard-print.pdf`
- 요약 카드: `og.png`

## 사용한 공공데이터

| 데이터 | 제공·출처 | 이용 조건 |
|---|---|---|
| 대구광역시_생활폐기물 처리_20241231 | 대구광역시 자원순환과, [공공데이터포털](https://www.data.go.kr/data/15130913/fileData.do) | 공공누리 제1유형(출처표시) |
| 전국 폐기물 발생 및 처리현황(2024년 실적) 6개 표 | 기후에너지환경부·한국환경공단, [자원순환마루](https://www.recycling-info.or.kr/sds/ntnProcessIndex.do?menuNo=M130309) | 공공데이터포털 [개방본](https://www.data.go.kr/data/3070174/fileData.do) 기준 이용허락범위 제한 없음 |

원자료의 수치는 바꾸지 않았고, 비율·1인당 값·합계만 계산했습니다.

## 분석 방법

- K-means 군집, 계층적 군집, 주성분 분석 (scikit-learn, SciPy)
- 매립 메탄 잠재량: IPCC 2006 지침 기본값 (매립가스 회수를 반영하지 않은 상한 추정)
- 시나리오 계산식과 한계는 대시보드의 "방법·출처" 섹션에 있습니다.

## 검증

`analysis/verify.py`가 대시보드에 쓴 수치 95개를 원자료에서 다른 계산 경로로 다시 계산해 대조합니다. 결과는 `analysis/검증결과.txt`에 있습니다(전부 일치).

원자료 파일은 저장소에 넣지 않았습니다. 위 출처에서 내려받아 `analysis/build_all.py`를 실행하면 같은 결과를 얻을 수 있습니다.
